# IBM Bob Task Session Summaries

The IBM Bob 2.0 hackathon requires the repository to include task-session summary screenshots for the project.

Place the exported/screenshot files from the IBM Bob task session summaries in this folder.

Recommended naming:

- `01-planning-summary.png`
- `02-build-summary.png`
- `03-debug-summary.png`

Do not place API keys, passwords, tokens, or other secrets in these screenshots.
